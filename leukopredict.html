LeukoPredict

LeukoPredict is a set of tools that make the diagnostic call directly from the raw data file of a laboratory instrument. They were developed for molecular leukemia diagnostics at Hannover Medical School, where the step from a finished instrument run to the reported result is still a manual inspection of curves and traces in the vendor software.

All tools follow one design. The features are computed from the raw instrument file. A trained model makes the call and returns a probability. A rule-based gate applies the run-acceptance criteria of the laboratory and defers every uncertain sample to a person, with the reason. Targets, reference genes, control names and thresholds are defined in a configuration file, so each tool can be trained for other assays. A laboratory scientist reviews and approves every run.

Availability

Each tool is a Bioconda package with its own documentation and version, and a Galaxy tool in the ToolShed under the owner mhh-hematology. Running the tools in Galaxy records the input file, the tool version, the parameters and the result of every call. 

conda create -n qpcrpredict -c conda-forge -c bioconda qpcrpredict

Intended use

The tools are research software and not certified in vitro diagnostic devices. The packaged models were trained on the data of one laboratory. Validate a model on local data, or train one, before relying on its output.
