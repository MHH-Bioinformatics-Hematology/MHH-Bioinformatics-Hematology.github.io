Privacy

Controller

Joachim Wolff, contact details in the legal notice.

What this website does and does not do

This website consists of static pages. It sets no cookies, uses no analytics or tracking, contains no contact forms, and loads no fonts, scripts, or other resources from third-party servers. The only script on the pages displays the contact email address, which is stored in a form that automated address collectors do not read.

Hosting and server logs

The website is hosted on GitHub Pages, a service of GitHub, Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, USA. When a page is requested, GitHub processes technical data that the browser transmits, in particular the IP address, date and time of the request, the requested page, and browser information. This is necessary to deliver the website and to keep the service secure (Art. 6 (1) (f) GDPR). The data may be processed in the USA. The operator of this website has no access to these logs. Details are given in the GitHub privacy statement.

External links

This website links to external websites, for example the Galaxy Training Network, GitHub, Google Scholar, ORCID, and publisher pages. Data is only transmitted to these providers when a link is followed. Their own privacy policies apply.

Email

If you send an email, the data you provide is used only to handle your request.
