# MHH Bioinformatics Hematology

MHH Bioinformatics Hematology develops and maintains bioinformatics software for hematology-focused research and diagnostics. Our work spans practical analysis tooling, Galaxy integrations, and agentic AI improvements that help extend and modernize established bioinformatics workflows.

## Focus areas

- building and improving tools for sequence analysis and variant interpretation
- maintaining reusable workflows and Galaxy tools for everyday bioinformatics work
- contributing to public Hi-C and 3D genomics tooling
- exploring agentic AI approaches to improve existing tools and workflows

## Public projects

- [vardictcpp](https://github.com/MHH-Bioinformatics-Hematology/vardictcpp) - public variant calling related development from the group
- [falcoAmadeus](https://github.com/joachimwolff/falcoAmadeus) - a public performance-focused sequencing QC tool
- [galaxytools](https://github.com/MHH-Bioinformatics-Hematology/galaxytools) - the Galaxy tools we maintain
- [HiCExplorer](https://github.com/deeptools/HiCExplorer) - Hi-C analysis software from the deepTools ecosystem that we reference and contribute around
- [hicGAN](https://github.com/kimmo1019/hicGAN) - a public Hi-C super-resolution project relevant to our work
